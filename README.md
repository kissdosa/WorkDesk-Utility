# WorkDesk Utility

Mac에서 개발하고 Windows용 앱으로 패키징하는 무료 데스크톱 업무 도구의 초기 버전입니다. UI는 가벼운 Apple 데스크톱 스타일을 참고했으며 Liquid Glass는 사용하지 않습니다.

## 현재 포함된 기능

- Windows 네트워크 프로필 편집: 사내 IP `10.225.135.113`, DNS `147.6.44.44 / 147.6.44.45`, DHCP 및 DNS `168.126.63.1 / 168.126.63.2` 기본값
- 폭·높이를 지정하고 잠금 상태로 기억하는 화면 영역 반복 캡처, PNG 저장 및 클립보드 복사
- 기본 계산 및 이미지의 숫자 OCR 합계
- 화면 캡처 결과를 OCR 계산기로 보내고, 선택한 업무 가이드 문서에 바로 삽입
- 제품 정보 버튼에 제작자, 제작일, 수정·책임 안내 표시
- AES-256-GCM 기반 로컬 암호 보관함과 계정 변경 이력 표시
- 브라우저 편집기를 이용한 서식/목록/표/이미지 가이드 작성
- 월간 격자형 업무 달력: 재택근무, 연차, 반차, 회식, 조기출근, 조기퇴근, 작업, 휴일, 기타 일정의 색상 표시, 상세 메모 및 매일·매주·매달 반복

네트워크 주소의 게이트웨이와 서브넷 프리픽스는 대화에 없어 자동 추정하지 않았습니다. 확인할 수 없습니다. 고정 IP를 적용하기 전에 올바른 값을 직접 입력해 주세요. 네트워크 설정 적용은 Windows 전용이며 UAC 관리자 승인이 필요합니다. macOS의 개발용 미리보기에서는 네트워크 설정이 바뀌지 않습니다.

## Mac에서 실행

1. Node.js 22.12 이상을 설치합니다.
2. 프로젝트 폴더에서 `npm install`을 실행합니다.
3. `npm run dev`로 앱을 실행합니다.
4. 브라우저에서 화면만 확인할 때는 `npm run preview:web`을 사용합니다. 브라우저 미리보기에서는 Electron 전용 캡처·클립보드·암호화 기능이 동작하지 않습니다.
5. `npm test`로 순수 로직 검사를 진행합니다.
6. `npm run build`로 타입 확인과 Mac 앱 디렉터리 빌드를 진행합니다.

## Windows 앱 만들기

간단한 경로는 프로젝트를 GitHub 저장소에 올린 뒤 `Actions`에서 `Windows build and checks`를 실행하는 것입니다. 이 프로젝트에는 Windows 호스트에서 단위 검사를 실행하고 portable 앱을 빌드해 artifact로 올리는 workflow가 포함되어 있습니다. GitHub Actions 무료 사용량은 계정 및 저장소 공개 설정에 따라 달라질 수 있습니다. Mac에서 직접 `npm run package:win`을 실행할 수도 있지만 Windows 도구 실행을 위해 Wine과 네트워크 다운로드가 필요할 수 있습니다. 생성된 실행 파일은 `release/` 폴더에 있습니다. 코드 서명 인증서가 없으면 Windows SmartScreen 경고가 표시될 수 있습니다. CI의 빌드는 패키징 확인이며, 실제 네트워크 어댑터에 대한 최종 전환 검증은 Windows 10/11 기기에서 해야 합니다.

## 개인정보와 보안 한계

보관함의 내용은 Electron 메인 프로세스에서 scrypt로 키를 파생해 AES-256-GCM으로 암호화한 뒤 `localStorage`에 암호문으로 저장합니다. 마스터 비밀번호는 저장하지 않습니다. 잊어버리면 복구할 수 없습니다. PC 잠금, 악성코드 감염, 화면을 잠금 해제한 상태의 사용자 접근을 막아 주는 기업용 비밀번호 관리자는 아니므로 중요 계정은 전용 보안 제품을 권장합니다. 현재 보관함은 앱 로컬 프로필에 저장되고 별도 백업/동기화는 없습니다.

## 단계별 개발 계획

1. **초기 앱 골격 (현재):** 여섯 페이지와 기본 동작, Windows 패키징 workflow 및 로직 단위 검사
2. **기능 다듬기:** OCR 표 셀/행/열 검토, 보관함 항목 편집/비밀번호 변경과 전체 이력 표시, 가이드 이미지 파일 저장
3. **Windows 검증:** 실제 어댑터 검색, 적용 실패 시 복구 동선, Windows 10/11에서 네트워크 전환 시험
4. **배포 준비:** 백업/복구, 접근성 및 오류 처리, 코드 서명과 설치 안내

캡처 페이지는 너비·높이를 픽셀로 입력하고 잠글 수 있으며 크기 설정은 기기에 저장됩니다. 잠금은 기본으로 켜지고, 잠금을 푼 뒤 수정하거나 기본 크기(700×180px)로 초기화할 수 있습니다. 미리보기의 빈 곳을 클릭해 프레임을 놓거나 프레임 자체를 드래그해 이동하고 “이 위치 캡처”를 누르면 같은 크기의 PNG를 반복 생성합니다. 복사와 저장은 최근 캡처 결과를 대상으로 합니다. 화면 미리보기는 최대 2560×1600 픽셀로 요청되므로 원본 모니터가 더 크면 캡처 이미지도 축소되어 프레임이 입력한 픽셀 크기보다 작아질 수 있습니다. 달력 반복은 종료일 없이 매일, 매주 같은 요일, 매달 같은 날짜에 표시됩니다. 짧은 달에 선택한 날짜(예: 31일)가 없으면 그 달에는 일정이 표시되지 않습니다. 반복 일정에서 저장하거나 삭제하면 전체 반복 일정에 반영됩니다. OCR은 이미지에서 숫자들을 읽어 합산하지만 행/열/셀 구분을 하지 않으므로 숫자가 아닌 화면 문구나 중복 표시가 함께 합산될 수 있습니다. OCR 엔진은 이미지 자체를 외부에 보내지 않고 기기에서 처리하지만, 첫 실행 시 엔진 코드와 영어 인식 모델 다운로드에 인터넷 연결이 필요합니다. 암호 보관함은 항목 저장, 암호 변경 및 이력 조회를 지원하지만, 이력에 보이는 과거 비밀번호는 보관함을 연 상태에서만 표시됩니다. 가이드 이미지는 앱 프로필의 로컬 브라우저 저장공간에 포함되므로 대용량 이미지를 많이 넣으면 저장 한도에 도달할 수 있습니다.

현재 ARM Mac에서 만든 테스트용 `.app`은 약 279 MB였습니다. 대부분이 Electron 런타임이며, 크기를 줄이려면 다음 단계에서 Tauri 같은 네이티브 셸로 전환할 수 있습니다. Windows용 크기는 실제 패키징 전에는 확인할 수 없습니다.

## 자동 검사

`npm test`는 주소 형식, 네트워크 명령 입력, 계산 입력의 안전성에 대한 순수 로직 검사를 실행합니다. UI와 실제 Windows 네트워크 장치의 동작 검증은 별도 Windows 기기에서 필요합니다.
